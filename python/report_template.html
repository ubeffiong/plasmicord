10 / METHODS & REPRODUCIBILITY

Run metadata, rules and interpretation limits

Software and database records

How to read the report

Plasmid unit: a run-local cluster defined by the recorded distance and linkage. It is not a fixed biological species or transmission event.

Dynamic interpretation: deterministic, versioned rules calculate findings from this result. Selected-view summaries recalculate as you filter; cohort findings remain labelled as cohort-wide.

Not evaluated: missing analysis is distinct from completion with zero detections. Imported features alone cannot establish annotation completeness.

Colour: every status includes a text label. Green/blue completion does not validate biological truth. Amber marks evidence needing review; grey denotes unevaluated evidence.
