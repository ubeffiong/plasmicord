# Repository attribution policy

- AI agents may perform work only within the permissions granted by the user.
  This policy does not expand those permissions.
- Do not credit Claude, Codex, ChatGPT, another AI agent, or an AI service as a
  repository contributor, commit author, committer, or co-author.
- Do not add AI attribution trailers (including `Co-authored-by`), contributor
  entries, authorship badges, or acknowledgements crediting agents as contributors.
- For user-authorized commits, use the maintainer's configured Git identity:
  `UbEffiong <ubokobongokon@gmail.com>`. Do not substitute an agent identity.
- Preserve legitimate human authorship and co-authorship. Do not rewrite existing
  human attribution merely to make it match the maintainer.
- Before committing or pushing, check author/committer identities and commit
  messages for unwanted AI attribution.
- This concerns authorship credit; accurate technical documentation of software
  or tools used by the project is still permitted.
